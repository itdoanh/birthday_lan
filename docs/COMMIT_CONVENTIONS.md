# Commit Conventions

Dùng [Conventional Commits](https://www.conventionalcommits.org/) với prefix:

- `feat:` — tính năng mới
- `fix:` — sửa bug
- `perf:` — cải thiện performance
- `refactor:` — tái cấu trúc code
- `style:` — thay đổi CSS/styling
- `docs:` — tài liệu
- `chore:` — dependency, build, config
- `wip:` — work in progress (không merge)

## Ví dụ

```
feat(countdown): add phase 3 LastMinute component
perf(3d): upgrade postFX to SSAO + SSR
docs: add GTA3D documentation
chore: upgrade Three.js to r169
```
